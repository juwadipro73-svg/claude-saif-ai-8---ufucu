# Saif Advance Calculator ⚡📱

An ultra-modern, high-performance Flutter mobile application combining Scientific calculations, Unit Conversions, Financial Loan EMI & Tax calculators, and persistent Calculation History.

---

## 🌟 Key Features

### 1. 🧮 Advanced Scientific Calculator
- **Trigonometric Functions**: `sin`, `cos`, `tan`, `asin`, `acos`, `atan` with instant **DEG / RAD** switching.
- **Logarithmic Functions**: Natural log (`ln`), Base-10 log (`log`).
- **Powers & Roots**: Square (`x²`), Custom exponent (`xʸ`), Square root (`√`).
- **Constants & Operators**: `π`, `e`, Factorials (`n!`), Percentage (`%`), Multi-level Parentheses `( )`.
- **Memory Storage**: `MC` (Clear), `MR` (Recall), `M+` (Add), `M-` (Subtract).
- **Haptic Feedback**: Tactile vibration feedback on button presses.

### 2. 📐 Comprehensive Unit Converter
- **Length**: Meters, Kilometers, Centimeters, Millimeters, Miles, Yards, Feet, Inches.
- **Weight**: Kilograms, Grams, Milligrams, Pounds, Ounces, Metric Tons.
- **Temperature**: Celsius (°C), Fahrenheit (°F), Kelvin (K).
- **Speed**: m/s, km/h, mph, knot.
- **Digital Storage**: Byte, KB, MB, GB, TB.
- **Quick Swap Button**: Invert input & output units instantly.

### 3. 💳 Financial Suite
- **Loan EMI Calculator**: Compute Monthly EMI, Total Interest Payable, and Total Payment breakdown with Principal, Interest %, and Tenure.
- **GST / Sales Tax Calculator**: Exclusive and Inclusive tax calculation for 5%, 12%, 18%, 28% tax slabs.

### 4. 📜 Calculation History
- Full history log with expression and result.
- Re-use result in subsequent calculations.
- One-tap copy & clear history.

## 🚀 Building & Running

### Requirements
- Flutter SDK `^3.24.0`
- Android Studio / Android SDK (API 34)
- Java 17

### Commands
```bash
# Get packages
flutter pub get

# Run on connected device/emulator
flutter run

# Build Signed Release APK
flutter build apk --release
```

Generated APK: `build/app/outputs/flutter-apk/app-release.apk`
